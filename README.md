# Enterprise Systems Administration & Automation Portfolio

## Overview

This portfolio demonstrates enterprise-grade systems administration and automation skills using PowerShell, CI/CD pipelines, and infrastructure monitoring concepts.

It simulates real-world IT operations environments including identity management, endpoint compliance, server maintenance, and centralized monitoring.
